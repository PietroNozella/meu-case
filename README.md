# Meu Case

Portfólio pessoal de Pietro Nozella, desenvolvido para apresentar projetos, stack e formas de contato em uma experiência responsiva.

**Demo:** [meu-case.vercel.app](https://meu-case.vercel.app)

## O que o projeto apresenta

- seleção de projetos recentes;
- stack e áreas de atuação;
- apresentação profissional;
- contato direto;
- navegação responsiva com animações e interações visuais.

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Motion, GSAP e OGL

## Execução local

Pré-requisito: Node.js compatível com as dependências do projeto.

```bash
npm install
npm run dev
```

A aplicação será disponibilizada pelo endereço informado pelo Vite no terminal.

## Validação

```bash
npm run build
npm run preview
```

## Estrutura principal

- `src/components`: componentes visuais e seções do portfólio;
- `src/content`: textos e dados apresentados na interface;
- `public`: imagens e demais recursos estáticos.
